# ANASS DEV | Digital Solutions Developer & AI Automation Specialist

Personal portfolio website of **Anass El Fatihi**, Digital Solutions Developer and AI Automation Specialist.

This project features a high-end, responsive, single-page interactive experience displaying custom dashboards, e-commerce applications, workflow automations, and creative works.

---

## 🚀 Key Features

- **Asymmetric Editorial Grid**: Project cards displaying custom works with desktop hover video playbacks and fullscreen preview modals.
- **Animated Work Process**: Interactive visual railway showcasing the development lifecycle from strategy to delivery.
- **Sound System**: Immersive ambient soundtrack and micro-interactions (SFX) that can be enabled by the user.
- **Cursor Spotlight & Spotlight Effects**: Sleek background gradients and halo glows responsive to user interaction.
- **Responsive Layout**: Designed for optimal desktop, tablet, and mobile presentation.
- **Performant Architecture**: Highly optimized image/video rendering, lazy loading, and modern CSS variables.

---

## 🛠️ Tech Stack

- **Framework**: [TanStack Start](https://tanstack.com/router/latest/docs/start/overview) (React & Vite-based full-stack framework)
- **Styling**: [Tailwind CSS v4](https://tailwindcss.com/)
- **Animations**: [Framer Motion](https://www.framer.com/motion/) & [GSAP](https://gsap.com/)
- **Icons**: [Lucide React](https://lucide.dev/) & [React Icons](https://react-icons.github.io/react-icons/)
- **Forms & Validation**: [React Hook Form](https://react-hook-form.com/) & [Zod](https://zod.dev/)

## 💻 Getting Started

### Prerequisites

Make sure you have Node.js (v18 or higher) and npm/bun installed.

### Installation

1. Clone the repository or navigate to the directory:

   ```bash
   cd anass-digital-canvas
   ```

2. Install dependencies:
   ```bash
   npm install
   ```

### Development Server

Run the development server locally:

```bash
npm run dev
```

Open `http://localhost:8080` in your browser.

### Production Build

To build the project for production:

```bash
npm run build
```

Preview the production build locally:

```bash
npm run preview
```
